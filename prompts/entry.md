Start one automatic code review in a dedicated write-critical coordinator. The tool launches it through pi-extended-teams and returns a short receipt and artifact paths, not the review itself. Context is plain text: include the problem, relevant prior decisions, URLs, tickets or extra direction. The coordinator does not inherit this conversation.

Use agentic_code_review when the user delegates a review, such as "review this for me". "I want to review" means interactive review tooling, not automatic reviewers. These examples are intent guidance, not special commands. A suggestion to review is not permission to start. Clarify genuinely ambiguous intent first.

Call once per requested run. Do not duplicate the coordinator's work, poll it, or invoke this tool again to finish the same review. Its report arrives through pi-extended-teams. The coordinator must not ask the user directly. If it sends a blocking question, ask the user in this invoking session while the coordinator waits. Relay the user's actual answer and any note with `send_message` to the same named coordinator from the receipt; do not answer on the user's behalf or launch a replacement. Until the user answers, keep it waiting. Silence, cancellation of a question dialog and other agent reports are not answers. An interrupted or unacknowledged launch may still start; do not automatically retry.
